```
┌──────────────────────────────────────────────────────────────┐
│  Current Problem: the agent Scouts Can't Write to Blackboard    │
└──────────────────────────────────────────────────────────────┘

    the agent Scout 1 ──X──> blackboard.json (READ-ONLY constraint violated)
    the agent Scout 2 ──X──> blackboard.json (READ-ONLY constraint violated)
```

## After (Fixed - Scribe Pattern)

```
┌──────────────────────────────────────────────────────────────────────┐
│  Solution: Scribe Agent Bridges READ-ONLY Scouts → Blackboard       │
└──────────────────────────────────────────────────────────────────────┘

┌─────────────────────┐
│   the agent Scout 1     │  Research topic 1
│   (READ-ONLY)       │
└──────────┬──────────┘
           │ write (allowed - result file)
           v
    ┌──────────────────┐
    │ scout-1-result   │
    │     .json        │
    └──────────────────┘
                                              ┌─────────────────────┐
┌─────────────────────┐                       │                     │
│   the agent Scout 2     │  Research topic 2     │  the agent Scribe      │
│   (READ-ONLY)       │                       │  (COORDINATOR)      │
└──────────┬──────────┘                       │                     │
           │ write (allowed - result file)    │  - Polls results/   │
           v                                   │  - Aggregates       │
    ┌──────────────────┐                      │  - Synthesizes      │
    │ scout-2-result   │─────── read ────────>│  - Posts updates    │
    │     .json        │                       │                     │
    └──────────────────┘                       └──────────┬──────────┘
                                                          │
           ...                                            │ write (allowed - the agent)
                                                          v
┌─────────────────────┐                       ┌────────────────────────┐
│   the agent Scout 10    │  Research topic 10    │   blackboard.json      │
│   (READ-ONLY)       │                       │                        │
└──────────┬──────────┘                       │  - Team coordination   │
           │ write (allowed - result file)    │  - Progress tracking   │
           v                                   │  - Phase management    │
    ┌──────────────────┐                      └────────────────────────┘
    │ scout-10-result  │─────── read ────────>              │
    │     .json        │                                    │
    └──────────────────┘                                    │
                                                            │ read (all agents)
                                                            v
                                                ┌────────────────────────┐
                                                │   All Team Members     │
                                                │   Monitor for Updates  │
                                                └────────────────────────┘
```

## Data Flow Sequence

```
TIME: T0 (Spawn)
┌────────────────────────────────────────────────────────────────┐
│  1. the agent spawns 11 agents: 10 the agent scouts + 1 the agent scribe  │
│  2. Blackboard initialized with 11 agent slots                │
│  3. Scribe starts monitoring loop (poll every 10s)            │
│  4. Scouts begin research in parallel                          │
└────────────────────────────────────────────────────────────────┘

TIME: T1 (Scouts Working)
┌────────────────────────────────────────────────────────────────┐
│  Scout 1: [research] ──> writes to scout-1-result.json        │
│  Scout 2: [research] ──> writes to scout-2-result.json        │
│  Scout 3: [research] ──> still working...                     │
│  ...                                                            │
│  Scribe: Polls results/ → finds 2 new files → reads them      │
│          Posts to blackboard: "2/10 scouts reported"           │
└────────────────────────────────────────────────────────────────┘

TIME: T2 (Mid-Progress)
┌────────────────────────────────────────────────────────────────┐
│  Scout 1-7: [DONE] ──> result files written                   │
│  Scout 8-10: [working]                                         │
│  Scribe: Polls results/ → finds 7 files total                 │
│          Reads new findings (scouts 3-7)                       │
│          Posts to blackboard: "7/10 scouts reported"           │
│          Early synthesis: "Common pattern emerging: X"         │
└────────────────────────────────────────────────────────────────┘

TIME: T3 (All Complete)
┌────────────────────────────────────────────────────────────────┐
│  Scout 1-10: [DONE] ──> all result files written              │
│  Scribe: Polls results/ → finds 10 files (all done!)          │
│          Aggregates all findings                               │
│          Identifies patterns across all scouts                 │
│          Posts synthesis to blackboard:                        │
│            "SYNTHESIS: All scouts found X. Pattern Y. Rec Z." │
│          Marks self as DONE                                    │
│          Writes scribe-synthesis.json with full report         │
└────────────────────────────────────────────────────────────────┘

TIME: T4 (the agent Review)
┌────────────────────────────────────────────────────────────────┐
│  the agent: Reads blackboard → sees synthesis                      │
│        Reads scribe-synthesis.json → full aggregated findings  │
│        Makes architectural decision based on synthesized data  │
│        Collapses swarm (cleanup)                               │
└────────────────────────────────────────────────────────────────┘
```

## Tier Constraint Enforcement

```
┌─────────────────────────────────────────────────────────────────┐
│  GUARDRAILS.md Lines 99-104: Model Tier Constraints            │
└─────────────────────────────────────────────────────────────────┘

| Tier   | Can Do                      | Cannot Do                  |
|--------|-----------------------------|----------------------------|
| the agent  | Read files, search, report  | Write files, make decisions|
|        | Write to blackboard         | Modify code                |
| the agent | Read + write files          | Architecture decisions     |
|        | Implement, refactor         | User communication         |
| the agent   | Everything                  | (Subject to other rules)   |

SCRIBE PATTERN COMPLIANCE:
✅ the agent writes to result files (not blackboard) → ALLOWED
✅ the agent reads blackboard for context         → ALLOWED
✅ the agent scribe writes to blackboard         → ALLOWED
✅ the agent scribe reads result files           → ALLOWED
✅ the agent makes final decisions                 → ALLOWED

No tier constraints violated. Architectural enforcement.
```

## API Endpoints Used

```
┌──────────────────────────────────────────────────────────────────┐
│  Scribe Agent API Operations                                     │
└──────────────────────────────────────────────────────────────────┘

1. Get all scout results (batch):
   GET http://localhost:7777/api/team/scout-results
   → Returns: [{agent, file, data, modified}, ...]

2. Post progress update:
   POST http://localhost:7777/api/blackboard
   Body: {"agent": "scribe", "message": "7/10 reported", "msg_type": "STATUS"}

3. Post synthesis:
   POST http://localhost:7777/api/blackboard
   Body: {"agent": "scribe", "message": "SYNTHESIS: ...", "msg_type": "SYNTHESIS"}

4. Mark done:
   POST http://localhost:7777/api/blackboard/done
   Body: {"agent": "scribe", "summary": "All scouts complete. Findings: ..."}

┌──────────────────────────────────────────────────────────────────┐
│  Scout Agent API Operations                                      │
└──────────────────────────────────────────────────────────────────┘

1. Read blackboard for context:
   GET http://localhost:7777/api/blackboard
   → Returns: {feature, phase, messages, agent_status, ...}

2. Write result file (local file write, NOT API):
   Write to: C:/Users/<user>/workspace/IHIM/team/results/scout-N-result.json

NO POST operations allowed for the agent scouts.
```

## Comparison: Old vs New Pattern

```
┌─────────────────────────────────────────────────────────────────┐
│  OLD: Blue Mode (10 the agent, no coordination)                     │
└─────────────────────────────────────────────────────────────────┘
10 the agent scouts → 10 result files → the agent reads all 10 manually
Pros: Fast, parallel
Cons: No mid-flight coordination, the agent does all synthesis

┌─────────────────────────────────────────────────────────────────┐
│  NEW: Scribe-Coordinated (10 the agent + 1 the agent)                 │
└─────────────────────────────────────────────────────────────────┘
10 the agent scouts → 10 result files → Scribe aggregates → 1 synthesis
                      ↓
                 Blackboard coordination (progress, patterns)
                      ↓
                 the agent reads 1 synthesis file

Pros: Coordinated, synthesized, progress tracking
Cons: +1 the agent cost, 5-10s latency
```

## Token Cost Analysis

```
┌─────────────────────────────────────────────────────────────────┐
│  Cost Breakdown                                                  │
└─────────────────────────────────────────────────────────────────┘

Blue Mode (10 the agent only):
  10 the agent scouts × ~2K tokens each         = 20K tokens
  the agent synthesis (manual)                    = 5K tokens
  ─────────────────────────────────────────────────────
  Total:                                       25K tokens

Scribe-Coordinated (10 the agent + 1 the agent):
  10 the agent scouts × ~2K tokens each         = 20K tokens
  1 the agent scribe × ~5K tokens              = 5K tokens
  the agent review (pre-synthesized)              = 2K tokens
  ─────────────────────────────────────────────────────
  Total:                                       27K tokens

Delta: +2K tokens (~8% increase)
Benefit: Coordinated execution, real-time progress, the agent workload ↓
```

## Success Metrics

```
A scribe swarm succeeds when:

✅ All expected scouts report findings
✅ Scribe posts progress updates (not silent)
✅ Synthesis identifies patterns across scouts
✅ Final synthesis file written
✅ Scribe marks self as DONE
✅ No scouts blocked or missing
✅ the agent reads 1 file instead of N files
```
